# ANAIS LunarNav Mission Dashboard — Development UI

This React/TypeScript dashboard is an API client for the existing Python scientific engine.

Start the backend:
```sh
python -m pip install -e '.[api,test]'
uvicorn anais_lunarnav.api:app --host 127.0.0.1 --port 8000
```

Start the frontend in another terminal:
```sh
cd frontend
npm install
npm run dev
```

Vite proxies /health and /v1 to localhost:8000. The Python backend requires the explicitly configured LUNARNAV_KERNEL_PATHS to calculate Sun/Earth visibility. When kernels are absent the user sees the authoritative backend error; the UI never substitutes illustrative geometry. The default dates are examples, not computed output.

For standalone production frontend hosting, configure VITE_API_BASE_URL for the approved scientific backend **and** explicitly configure permitted CORS origins or a same-origin reverse proxy. No public production backend, HTTPS deployment, or front-to-backend production verification is claimed.

The comparison uses point-target geometric snapshots. No exact visibility intervals, duration integrals, terrain-aware analysis or landing-safety claims are implemented. The backend is authoritative; the frontend only displays its results.

Reproducibility note: add a committed package-lock.json (generated by npm install) and update CI to npm ci before calling the frontend dependency graph release-locked.
